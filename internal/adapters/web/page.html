Connection helpLocal agents, Docker and T3 delivery

Local agent

Run the bundled Python bridge alongside your agent, with persistent bridge state and the agent’s credentials. The bridge polls for due reminders and invokes the agent.

Docker

On the Compose network, use http://schedulerse:8789. A bridge on the host uses the published service address. Install the agent runtime where the bridge runs.

T3 conversations

Use a reachable native T3 webhook for reminders in a T3 thread. Follow the T3 guide included in the delivery kit.

A reminder is still pending?

Check that the bridge is running, the token is valid and the service is reachable. Download the delivery kit again if the service address changed. Inspect Agent schedules for delivery results.
