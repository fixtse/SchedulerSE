# SchedulerSE logos

- `schedulerse-full.svg` / `.png`: full wordmark for dark backgrounds.
- `schedulerse-full-light.svg` / `.png`: full wordmark for light backgrounds.
- `schedulerse-mini.svg` / `.png`: compact clock-and-spark mark.
- `favicon.ico`: 16, 32 and 48 pixel browser icons.

SVGs contain outlined lettering and require no external fonts. PNGs have transparent backgrounds. Full PNGs are 1600 pixels wide; the mini PNG is 512 × 512.
